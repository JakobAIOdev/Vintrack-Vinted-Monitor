# Zahlarten für Oneclick auswählen

Öffne **Account → Oneclick checkout**. Die verfügbaren Vorgaben richten sich
nach der Region deines verknüpften Vinted-Kontos. Guthaben, gespeicherte Karte,
Google Pay und Vinteds gespeicherte Zahlart gehören zur gemeinsamen Vorauswahl.
Zusätzliche regionale Vorgaben:

| Region | Zusätzliche Zahlarten |
| --- | --- |
| Deutschland | PayPal, Tink, Klarna |
| Österreich | PayPal |
| Belgien | PayPal, Bancontact Pay |
| Niederlande | iDEAL / Wero |
| Polen | BLIK, Przelewy24 |

Maßgeblich bleibt das Angebot im tatsächlichen Vinted-Checkout. Eine gespeicherte
Vorgabe garantiert nicht, dass Vinted sie für jeden Kauf anbietet. Apple Pay ist
für diesen Web-Ablauf nicht auswählbar.

## Speichern und prüfen

1. Wähle eine angebotene Zahlart und Lieferung aus.
2. Speichere die Vorgaben.
3. Öffne den Checkout und prüfe Vinteds endgültige Auswahl, Versand und Gebühren.

Bei mehreren gespeicherten Karten muss die gewünschte Karte bereits in Vinted
ausgewählt sein. Fehlende, deaktivierte oder uneindeutige Optionen bleiben zur
manuellen Prüfung offen. Vorgaben sind an dein verknüpftes Konto und dessen
Region gebunden.

Normaler Oneclick bereitet den Checkout vor und stoppt vor der Zahlung.
Automatische Zahlung benötigt eine zusätzliche ausdrückliche Aktivierung für
[PayPal](checkout-auto-paypal.md) oder eine [gespeicherte Karte](checkout-auto-card.md).
