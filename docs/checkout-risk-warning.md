# Checkout risk warning

Every member must explicitly accept the checkout risk warning before using
Oneclick or automatic checkout. Account linking and earlier payment opt-ins do
not replace this acceptance. A changed warning can require acceptance again.

The warning explains possible Vinted account restrictions, technical errors,
outdated prices or shipping choices, unclear outcomes and unintended payments.
Read the full current wording in the application before deciding to continue.

## Accept or cancel

The checkbox starts unchecked. Check it only after reading the warning, then
choose the confirmation action. **Cancel** or Escape ends the pending checkout.
A saving error leaves the dialog open and does not start checkout.

For automatic checkout, continuing can start a real payment. Turning on
automatic checkout also requires a separate payment warning and a saved
spending limit. The switch stays off if you cancel.

Acceptance is stored on your signed-in Vintrack account. It is independent of
account linking and payment preferences. Review the final item, delivery,
payment method and total in Vinted whenever manual confirmation is required.

See [checkout setup](checkout-module.md), [saved-card payment](checkout-auto-card.md)
and [PayPal payment](checkout-auto-paypal.md) for the corresponding controls.
