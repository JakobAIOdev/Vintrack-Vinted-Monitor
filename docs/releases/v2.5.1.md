# v2.5.1 · Faster checkout preparation

Extension: **0.3.3** (Chrome and Firefox; checkout protocol remains 6).

Normal Oneclick avoids a redundant Vinted checkout update when the fresh build
already confirms the requested home delivery, saved address, shipping rate,
enabled native payment selection and checksum. Unknown, incomplete or different
selections keep the existing update flow. The service fallback applies the same
optimization.

Automatic PayPal/card payment continues to obtain and verify the final quote
with a checkout update. Account identity checks, risk acceptance, limits and
durable replay checkpoints remain required. There are no automatic retries.

Optional extension link history no longer delays navigation to the native
checkout. Normal Oneclick also prefetches the next route during the preference
update and can use Vinted's existing Next.js client router to avoid a full
document reload. Missing/failed routing falls back to opening the same prepared
URL, without repeating checkout preparation. An already open normal checkout
is focused without reloading it. Automatic payment/resume links keep the full
native handoff. Vinted still fetches and validates its current quote; responses
are not cached or intercepted.

Numeric timing diagnostics include `updateSkipped` and `clientNavigation`
(0 or 1), plus `navigationMs`, without account data, URLs or payment responses.

No database migration or new configuration is required. Update the GitHub
Actions variable `BROWSER_EXTENSION_LATEST_VERSION` to **0.3.3** when releasing;
the minimum compatible extension version stays **0.2.1**. Reload an unpacked
development extension to test the new path.

Performance depends on whether Vinted's build already contains matching
selections. This optimization removes one request in that case; it does not
remove the subsequent native checkout page load.

The native-router integration is optional and depends on the router Vinted
currently exposes. Changes to Vinted may disable this optimization; ordinary
checkout navigation remains available.
